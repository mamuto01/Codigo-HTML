Preparar o sorteio

Cole até 10 nomes, um por linha. O sistema cria um código pessoal para cada pessoa e faz o sorteio uma única vez. Entregue cada código em particular ao participante correspondente.

Códigos para entregar em particular

Copie ou anote cada código e envie somente para a pessoa indicada. Não publique esta lista no grupo.

A tela não mostra os pares sorteados. Ainda assim, quem administra o projeto de banco de dados pode ter acesso técnico aos dados armazenados; esta versão não oferece garantia criptográfica de anonimato contra o administrador da hospedagem.
